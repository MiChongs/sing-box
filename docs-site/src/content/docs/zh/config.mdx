Smart 的配置分三处：出站组本身（`type: "smart"`，或按地区分摊连接的 `type: "smart-loadbalance"`）、全局的 `experimental.smart`（LightGBM 模型与训练数据），以及全局的 `experimental.geox`（ASN 与国家数据库下载）。另外，Smart 的学习数据保存在 `experimental.cache_file` 中。

## 结构总览

```json
{
  "outbounds": [
    {
      "type": "smart",
      "tag": "auto",

      "outbounds": [],
      "providers": [],
      "use_all_providers": false,
      "include": "",
      "exclude": "",

      "url": "https://www.gstatic.com/generate_204",
      "interval": "3m",
      "expected_status": "",

      "algorithm": "strict-best",
      "hysteresis": "0s",
      "policy_priority": "",
      "interrupt_exist_connections": false,
      "disable_udp": false,

      "use_lightgbm": false,
      "collect_data": false,
      "sample_rate": 1.0,
      "max_host_failed_times": 10,

      "use_asn": false,
      "asn_database": [],

      "hidden": false,
      "icon": ""
    }
  ],
  "experimental": {
    "cache_file": { "enabled": true },
    "smart": {
      "lightgbm": {
        "model_path": "smart_lgbm_model.bin",
        "url": "",
        "auto_update": false,
        "update_interval": "72h",
        "http_client": "",
        "download_detour": ""
      },
      "collector": {
        "path": "smart_weight_data.csv",
        "size_limit_mb": 100
      }
    },
    "geox": {
      "enabled": false,
      "auto_update": false,
      "update_interval": "24h",
      "download_detour": "",
      "url": { "asn": [], "mmdb": "", "geoip": "", "geosite": "" }
    }
  }
}
```

<Callout type="warn" title="必须开启 cache_file">
  Smart 的统计、权重、排名、手动指定、熔断状态都保存在缓存文件的 `smart_stats` bucket 中。没有缓存文件时，Smart 不记录任何统计，只按 URL 测速延迟选路。命令行版本需要设置 `experimental.cache_file.enabled: true`；SFA / SFW / SFL 图形客户端始终启用缓存文件。
</Callout>

<Callout type="danger" title="不支持的字段">
  `tolerance` 与 `idle_timeout` 是 `urltest` 的字段，Smart 从未支持。配置中出现未知字段会直接报错：`outbounds[0].tolerance: json: unknown field "tolerance"`。早期文档曾错误列出这两个字段，请从配置中删除。
</Callout>

## smart-loadbalance

`smart-loadbalance` 组接受上面 `smart` 组的全部字段，含义不变，只有 `algorithm` 与 `hysteresis` 被忽略（启动时记录 WARN），分别由 `balance` 与 `region` 取代。工作方式见 [Smart 负载均衡](../smart-loadbalance/)。与 `algorithm` 不同，`balance`、`region` 中的取值写错会直接报配置错误。

```json
{
  "type": "smart-loadbalance",
  "tag": "balance",
  "providers": ["my-subscription"],

  "balance": {
    "strategy": "smart",
    "affinity": "none",
    "affinity_ttl": "10m",
    "max_nodes": 0,
    "min_quality": 0.5,
    "max_connections_per_node": 0
  },
  "region": {
    "mode": "auto",
    "priority": [],
    "allow": [],
    "deny": [],
    "weights": {},
    "fallback": "auto",
    "min_nodes": 1,
    "sticky": "30m",
    "switch_margin": 0.25,
    "unknown": "keep",
    "rules": [],
    "destination": { "map": {}, "disable_tld": false, "disable_resolve": false },
    "detect": {
      "disable_name": false,
      "exit": "fallback",
      "exit_url": "https://www.cloudflare.com/cdn-cgi/trace",
      "exit_ttl": "24h",
      "exit_timeout": "8s",
      "exit_concurrency": 4
    },
    "probe": { "disabled": false, "interval": "10m", "targets": 6, "regions": 5 },
    "outbounds": {
      "enabled": false,
      "regions": [],
      "auto": false,
      "tag": "{group}-{region}",
      "fallback": false,
      "members": "regions",
      "hidden": false,
      "icon": ""
    }
  }
}
```

地区可以写代码（`HK`、`GB`，`UK` 等同 `GB`）、中英文名称（`香港`、`Japan`）或旗帜（`🇯🇵`），不区分大小写；不认识的值按大写原样作为自定义地区。

## smart-region

`smart-loadbalance` 组某个地区的出站。通常由 `region.outbounds` 自动生成，也可以手动声明。经它的连接走所属组的完整流程，地区固定。

```json
{ "type": "smart-region", "tag": "日本前置", "group": "balance", "region": "JP", "fallback": false }
```

## experimental.smart

所有 Smart 组共享的模型与训练数据采集器。这一块没有 `enabled` 开关，也不需要显式填写：只有当某个组设置了 `use_lightgbm` 才会加载、下载模型；只有当某个组设置了 `collect_data` 才会创建 CSV。

## experimental.geox

全局地理数据下载。目前**唯一的使用者是 Smart**：`url.asn` 为未设置 `asn_database` 的组提供 ASN 数据库，`url.mmdb` 提供国家数据库（LightGBM、训练数据采集与 `smart-loadbalance` 的 `destination` 模式使用）。各项没有默认下载地址，只有填写了 URL 的文件才会下载。文件名固定，保存在数据目录下。

<FieldList lang="zh" fields={geoxFields} prefix="geox-" />

<Callout type="note" title="首次下载与生效时机">
  GeoX 在后台下载，不阻塞启动。Smart 启动时文件还没下载好也没关系：数据库下载或更新完成后立即重新加载，所有组随即使用新数据，**无需重启**。
</Callout>
