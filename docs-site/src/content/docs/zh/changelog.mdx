只列出影响使用的变化，按时间倒序。完整提交历史见 [GitHub](https://github.com/MiChongs/sing-box/commits/xiaobaf14g-testing)。

## 2026-10

**ASN 与国家数据库热重载，下载完整接入 http_client**（10-07）

- GeoX 下载或更新 ASN、国家数据库后立即重新加载，所有 Smart 组随即使用新数据；启动时还没下载好的数据库在下载完成后自动启用。此前都需要重启。
- 默认的 ASN、国家数据库改由 GeoX 在后台下载，使用 GeoX 的 `http_client`、`auto_update` 与 `update_interval`。启动不再被下载阻塞，已有的 ASN 库也不再在每次启动时重新下载。
- GeoX、LightGBM 模型与默认数据库的下载使用 `http_client` 的全部设置（出站与其他拨号选项、TLS、请求头、HTTP 版本），此前只采用其中的出站。都没有设置时使用默认 HTTP 客户端。
- 缺失文件下载失败时按 30 秒起、最长 30 分钟的间隔重试，不再等到下一个更新周期或重启。
- 国家数据库只在开启 `use_lightgbm` 或 `collect_data` 的组中打开与下载。

**LightGBM 兼容 v4 模型**（10-07）

- 模型解析改为支持 LightGBM v2–v4 文本格式，包括线性树。此前默认模型 `Model-large.bin`（v4 格式）无法加载，启用 `use_lightgbm` 实际一直使用传统公式。
- 模型输入改为按 `feature_names` 匹配特征名，默认模型的 30 维布局得以正确读取；新增 `history_duration_minutes`、`loss_rate`、`cumul_loss_rate` 三个特征。
- 无法使用的模型会被拒绝并记录原因，启动日志显示 `ml=unusable`。`[transforms]` 块校验失败时不再忽略该块继续加载模型。
- `auto_update` 关闭时，已存在但无法使用的模型文件不再在每次启动时重新下载。
- 训练数据格式升级到第 5 版：新增第 59–61 列，共 63 列。

**学习数据真正生效并跨重启保留**（10-07）

- 修复 Smart 组拿不到缓存文件数据库的问题。自 2026-06-08 起，统计、权重、LightGBM 推理、训练数据采集与持久化实际都没有工作，Smart 只按测速延迟选路。
- 修复缓存文件打开时删除 `smart_stats` 的问题，此前学习数据会在每次启动、SIGHUP 或 Clash API 重载时被清空。
- 重新加载配置后，Smart 改用新打开的缓存文件，不再读写已关闭的旧数据库。

**训练数据 CSV 表头与数据列对齐**（10-07）

- 表头改为与数据行一致的 60 个列名，可以直接按列名读取。
- 表头与当前格式不一致的已有文件（包括旧的 37 列表头）会被改名为 `.bak.<时间戳>` 备份后新建；空文件会补写表头。

**连接出站链补全到实际节点**（10-06）

- `/connections` 中经过 Smart 的连接，`chains` 现在包含实际拨通的节点，最终节点在前，如 `["HK-01", "auto", "proxy"]`。成员是嵌套策略组时逐级展开。
- `DELETE /connections/smart/{id}` 屏蔽这条连接**实际使用**的节点，而不是组当前的 `now`。
- SFA / SFW / SFL 的连接列表同步显示实际节点。

**修复长连接 30 秒被切断**（10-05）

- 首字节超时改为在客户端首次写入时开始、收到首字节即解除；卡死只认“写出后 60 秒无任何回应”。此前经过 Smart 的长连接会在第 30 秒被切断，并把健康节点误判为失败。
- 探测超时改为从开始执行时计算，排队时间不再被当作节点失败。
- 探测与统计改用专用队列：相同节点的探测跨组合并；统计队列满时丢弃样本，不再阻塞连接关闭。
- 设备休眠或时钟跳变后，周期任务从当前时间继续，不再连续补跑。
- 每条连接的 Info 日志降为 Debug；国家查询只在启用 LightGBM 或数据采集时执行。

**存储层重构**（10-05）

- 预取与按目标选路改用增量统计索引：预取 800 个目标从约 745 ms 降到约 32 ms，按目标选路从约 530 µs 降到约 0.6 µs。
- 移除每条记录约 22 KB 的 t-digest，旧数据照常加载。
- 修复：删除 `node-1` 会连带删除 `node-10`；扫描组 `HK` 会扫到 `HK-Auto`；写入后最多 300 秒读到旧值；名称含 `/` 的节点在清理时被误删统计。

## 2026-06

**大规模节点下降低占用**（06-12）

- 健康检查改为“前 16 名必测 + 轮转预算 + 失败指数退避”，500 个节点时每轮探测从约 500 次降到约 66 次。
- 排名重算的最小间隔随节点数放宽。
- 内存缓存改为按实际字节计量，`SMART_CACHE_BUDGET_MB` 成为真实的内存上限。
- LightGBM 推理结果缓存 30 秒；事件计数表设上限 4096。

**启动时自动下载缺失文件**（06-08）

- 启用 `use_lightgbm` 而模型文件不存在时，即使没有开启 `auto_update` 也会下载一次。
- 启用 `use_asn` 而没有 ASN 数据库时自动下载 GeoLite2-ASN；缺少国家数据库时自动下载 GeoLite2-Country。

**LightGBM 特征扩展到 35 维**（06-08）

- 新增延迟与建连标准差、短长期 RTT 差、短期成功率、活跃连接数、TLS 握手耗时、小时、TCP 重传共 8 维；27 维旧模型仍可使用。
- 训练数据格式升级到第 4 版。
- 新增 `POST /smart/groups/{name}/recompute` 与 `POST /smart/groups/{name}/clear-selection`；`/smart/groups` 新增 `pinSuspended` 字段。

## 2026-04

- **切网与内存**：修复网络切换、中断时 CPU 占满与内存暴涨；新增失败风暴门控；切网时取消进行中的拨号并优先预热手动指定的节点。
- **快速切换**：新增对冲拨号与并发恢复，节点断开后更快切走；单节点失败即标记不可用；竞速失败方的连接会被关闭。
- **手动指定**：只在真实拨号失败时临时绕过，失败后的回退同样遵循选路算法（TCP 与 UDP），状态同步到 Clash API；修复指定后不生效、未遵循 `interrupt_exist_connections` 的问题。
- **目标可疑度**：按目标过滤“假存活”节点，新增 TLS 握手探测。
- **新能力**：`consistent-hashing` 算法；请求场景重排与自适应并行拨号；流媒体与下载场景的带宽加分；`expected_status`；LightGBM 与 GeoX 支持 `http_client`。

## 本次文档重写更正的内容

旧文档中与源码不符的内容：

| 旧文档 | 实际 |
|---|---|
| 字段 `tolerance`、`idle_timeout` | Smart 不支持，写入会导致配置报错 |
| 11 种排序算法 | 10 种 |
| LightGBM 使用 27 维以上特征，与传统权重结合 | 按模型的特征名从 38 个特征中取值（默认模型用 30 个）；模型输出直接替代传统公式 |
| 识别 22 种致命错误 | 7 个重置子串 + 系统错误码，首字节之后另有 26 个子串与 GOAWAY 规则 |
| 首字节后 30 秒无数据即判卡死 | 写出后 60 秒无任何回应才判卡死，空闲连接不受影响 |
| 线性降权 + 30 分钟以上冷却 | 单次失败即不可用 3 分钟；熔断 15 秒起；累计 30 次失败才屏蔽 93 分钟起 |
| 按（目标 ASN, 节点）独立学习 | 统计按（目标, 节点）；ASN 只决定权重槽位，选路时汇总同 ASN 的所有目标 |
| `max_host_failed_times` 超过后不再降级该 host 对应的节点 | 计数按（组, 目标），劣化 +1、正常 −1 |
| `PUT /smart/groups/{name}/algorithm` 的请求体为字符串 | 必须是 `{"algorithm": "..."}` |
| 屏蔽节点时长取熔断配置 | 默认固定 30 分钟，可用 `duration` 参数指定 |
| GeoX 的 `geoip`、`geosite` 供其他场景使用 | 目前没有组件读取这两个文件 |
