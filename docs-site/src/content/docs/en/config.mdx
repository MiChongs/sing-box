Smart is configured in three places: the group itself (`type: "smart"`), the global `experimental.smart` (LightGBM model and training data), and the global `experimental.geox` (ASN and country database downloads). In addition, Smart's learned data is stored in `experimental.cache_file`.

## Structure overview

```json
{
  "outbounds": [
    {
      "type": "smart",
      "tag": "auto",

      "outbounds": [],
      "providers": [],
      "use_all_providers": false,
      "include": "",
      "exclude": "",

      "url": "https://www.gstatic.com/generate_204",
      "interval": "3m",
      "expected_status": "",

      "algorithm": "strict-best",
      "hysteresis": "0s",
      "policy_priority": "",
      "interrupt_exist_connections": false,
      "disable_udp": false,

      "use_lightgbm": false,
      "collect_data": false,
      "sample_rate": 1.0,
      "max_host_failed_times": 10,

      "use_asn": false,
      "asn_database": [],

      "hidden": false,
      "icon": ""
    }
  ],
  "experimental": {
    "cache_file": { "enabled": true },
    "smart": {
      "lightgbm": {
        "model_path": "smart_lgbm_model.bin",
        "url": "",
        "auto_update": false,
        "update_interval": "72h",
        "http_client": "",
        "download_detour": ""
      },
      "collector": {
        "path": "smart_weight_data.csv",
        "size_limit_mb": 100
      }
    },
    "geox": {
      "enabled": false,
      "auto_update": false,
      "update_interval": "24h",
      "download_detour": "",
      "url": { "asn": [], "mmdb": "", "geoip": "", "geosite": "" }
    }
  }
}
```

<Callout type="warn" title="cache_file must be enabled">
  Smart's stats, weights, ranking, pins and circuit breaker state are all stored in the `smart_stats` bucket of the cache file. Without a cache file, Smart records no stats and selects nodes only by URL test latency. The command-line version needs `experimental.cache_file.enabled: true`; the SFA / SFW / SFL GUI clients always enable the cache file.
</Callout>

<Callout type="danger" title="Unsupported fields">
  `tolerance` and `idle_timeout` are `urltest` fields, and Smart has never supported them. An unknown field in the config causes an error: `outbounds[0].tolerance: json: unknown field "tolerance"`. Earlier documentation listed these two fields by mistake. Remove them from your config.
</Callout>

## experimental.smart

The model and training data collector shared by all Smart groups. This block has no `enabled` switch and does not need to be written explicitly: the model is loaded and downloaded only when some group sets `use_lightgbm`, and the CSV is created only when some group sets `collect_data`.

## experimental.geox

Global geo data download. Currently **Smart is the only consumer**: `url.asn` provides the ASN database for groups that do not set `asn_database`, and `url.mmdb` provides the country database. No entry has a default download URL; only files with a URL set are downloaded. File names are fixed, and the files are saved in the data directory.

<FieldList lang="en" fields={geoxFields} prefix="geox-" />

<Callout type="note" title="First download and when it takes effect">
  GeoX downloads asynchronously during startup, while Smart opens the databases when startup completes. On the first run the files are often not downloaded yet, so the ASN feature is turned off. **You need to restart once after the download finishes for it to take effect.** Later automatic updates are likewise read by Smart only at the next start.
</Callout>
