Smart is configured in three places: the group itself (`type: "smart"`, or `type: "smart-loadbalance"` to spread connections by region), the global `experimental.smart` (LightGBM model and training data), and the global `experimental.geox` (ASN and country database downloads). In addition, Smart's learned data is stored in `experimental.cache_file`.

## Structure overview

```json
{
  "outbounds": [
    {
      "type": "smart",
      "tag": "auto",

      "outbounds": [],
      "providers": [],
      "use_all_providers": false,
      "include": "",
      "exclude": "",

      "url": "https://www.gstatic.com/generate_204",
      "interval": "3m",
      "expected_status": "",

      "algorithm": "strict-best",
      "hysteresis": "0s",
      "policy_priority": "",
      "interrupt_exist_connections": false,
      "disable_udp": false,

      "use_lightgbm": false,
      "collect_data": false,
      "sample_rate": 1.0,
      "max_host_failed_times": 10,

      "use_asn": false,
      "asn_database": [],

      "hidden": false,
      "icon": ""
    }
  ],
  "experimental": {
    "cache_file": { "enabled": true },
    "smart": {
      "lightgbm": {
        "model_path": "smart_lgbm_model.bin",
        "url": "",
        "auto_update": false,
        "update_interval": "72h",
        "http_client": "",
        "download_detour": ""
      },
      "collector": {
        "path": "smart_weight_data.csv",
        "size_limit_mb": 100
      }
    },
    "geox": {
      "enabled": false,
      "auto_update": false,
      "update_interval": "24h",
      "download_detour": "",
      "url": { "asn": [], "mmdb": "", "geoip": "", "geosite": "" }
    }
  }
}
```

<Callout type="warn" title="cache_file must be enabled">
  Smart's stats, weights, ranking, pins and circuit breaker state are all stored in the `smart_stats` bucket of the cache file. Without a cache file, Smart records no stats and selects nodes only by URL test latency. The command-line version needs `experimental.cache_file.enabled: true`; the SFA / SFW / SFL GUI clients always enable the cache file.
</Callout>

<Callout type="danger" title="Unsupported fields">
  `tolerance` and `idle_timeout` are `urltest` fields, and Smart has never supported them. An unknown field in the config causes an error: `outbounds[0].tolerance: json: unknown field "tolerance"`. Earlier documentation listed these two fields by mistake. Remove them from your config.
</Callout>

## smart-loadbalance

A `smart-loadbalance` group accepts every field of the `smart` group above with the same meaning, except `algorithm` and `hysteresis`, which are ignored (with a WARN at startup) and replaced by `balance` and `region`. See [Smart load balancing](../smart-loadbalance/) for how it works. Unlike `algorithm`, an invalid value in `balance` or `region` is a config error.

```json
{
  "type": "smart-loadbalance",
  "tag": "balance",
  "providers": ["my-subscription"],

  "balance": {
    "strategy": "smart",
    "affinity": "none",
    "affinity_ttl": "10m",
    "max_nodes": 0,
    "min_quality": 0.5,
    "max_connections_per_node": 0
  },
  "region": {
    "mode": "auto",
    "priority": [],
    "allow": [],
    "deny": [],
    "weights": {},
    "fallback": "auto",
    "min_nodes": 1,
    "sticky": "30m",
    "switch_margin": 0.25,
    "unknown": "keep",
    "rules": [],
    "destination": { "map": {}, "disable_tld": false, "disable_resolve": false },
    "detect": {
      "disable_name": false,
      "exit": "fallback",
      "exit_url": "https://www.cloudflare.com/cdn-cgi/trace",
      "exit_ttl": "24h",
      "exit_timeout": "8s",
      "exit_concurrency": 4
    },
    "probe": { "disabled": false, "interval": "10m", "targets": 6, "regions": 5 },
    "outbounds": {
      "enabled": false,
      "regions": [],
      "auto": false,
      "tag": "{group}-{region}",
      "fallback": false,
      "members": "regions",
      "hidden": false,
      "icon": ""
    }
  }
}
```

Regions can be written as codes (`HK`, `GB`; `UK` means `GB`), Chinese or English names (`香港`, `Japan`) or flags (`🇯🇵`), case-insensitively; anything else is taken upper-cased as a custom region.

## smart-region

The outbound of one region of a `smart-loadbalance` group, usually generated by `region.outbounds` but also declarable by hand. Connections through it run the group's full pipeline with the region fixed.

```json
{ "type": "smart-region", "tag": "japan-front", "group": "balance", "region": "JP", "fallback": false }
```

## experimental.smart

The model and training data collector shared by all Smart groups. This block has no `enabled` switch and does not need to be written explicitly: the model is loaded and downloaded only when some group sets `use_lightgbm`, and the CSV is created only when some group sets `collect_data`.

## experimental.geox

Global geo data download. Currently **Smart is the only consumer**: `url.asn` provides the ASN database for groups that do not set `asn_database`, and `url.mmdb` provides the country database (used by LightGBM, data collection and the `destination` mode of `smart-loadbalance`). No entry has a default download URL; only files with a URL set are downloaded. File names are fixed, and the files are saved in the data directory.

<FieldList lang="en" fields={geoxFields} prefix="geox-" />

<Callout type="note" title="First download and when it takes effect">
  GeoX downloads in the background without blocking startup. It does not matter if the files are not downloaded yet when Smart starts: when a database is downloaded or updated, it is reloaded at once and every group uses the new data, **with no restart**.
</Callout>
