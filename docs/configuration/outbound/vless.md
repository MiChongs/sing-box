### Structure

```json
{
  "type": "vless",
  "tag": "vless-out",
  
  "server": "127.0.0.1",
  "server_port": 1080,
  "uuid": "bf000d23-0752-40b4-affe-68f7707a9661",
  "flow": "xtls-rprx-vision",
  "encryption": "",
  "network": "tcp",
  "tls": {},
  "packet_encoding": "",
  "multiplex": {},
  "transport": {},

  ... // Dial Fields
}
```

### Fields

#### server

==Required==

The server address.

#### server_port

==Required==

The server port.

#### uuid

==Required==

VLESS user id.

#### flow

VLESS Sub-protocol.

Available values:

* `xtls-rprx-vision`

Without `encryption`, `xtls-rprx-vision` requires TLS or REALITY directly on the connection (no `transport`).

#### encryption

VLESS Encryption, compatible with Xray-core.

Format: `mlkem768x25519plus.<appearance>.<rtt>.[padding.]<client key>`

| Part       | Values                                                                                                   |
|------------|----------------------------------------------------------------------------------------------------------|
| appearance | `native` (TLS records), `xorpub` (obfuscated public keys) or `random` (fully random bytes), must match the server |
| rtt        | `0rtt` to resume sessions with tickets issued by the server, or `1rtt`                                   |
| padding    | Optional padding length/gap parameters, e.g. `100-111-1111.75-0-111.50-0-3333`                          |
| client key | X25519 password or ML-KEM-768 client key, generated by `sing-box generate vless-encryption`              |

With encryption enabled, `xtls-rprx-vision` works on every transport and without TLS.

Empty or `none` to disable.

#### network

Enabled network

One of `tcp` `udp`.

Both is enabled by default.

#### tls

TLS configuration, see [TLS](/configuration/shared/tls/#outbound).

#### packet_encoding

UDP packet encoding, xudp is used by default.

| Encoding   | Description           |
|------------|-----------------------|
| (none)     | Disabled              |
| packetaddr | Supported by v2ray 5+ |
| xudp       | Supported by xray     |

#### multiplex

See [Multiplex](/configuration/shared/multiplex#outbound) for details.

#### transport

V2Ray Transport configuration, see [V2Ray Transport](/configuration/shared/v2ray-transport/).
